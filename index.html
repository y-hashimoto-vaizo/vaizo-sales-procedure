ENTER に込めた意味

AIに触れる人を、
一人でも多く。

01 — 実行
ENTER
＝ 自ら動く
「依頼されてから作る」を壊す。決められた枠の中だけで動かず、自らの手でスピーディーに課題を解決する事業のスタンス。
02 — エンターキー
ENTER
＝ 押すだけ
完成品を先出しで提案。何ヶ月もの要件定義は不要。クライアントは目の前のサイトを見て「これでいく」とエンターキーを押すだけ。
03 — 突き抜ける
ENTER
＝ 突破する
属人化の壁を、業界の当たり前を、既存の枠組みを、すべて突き抜ける。VAIZOの構造的優位はここから生まれる。
外部 EXTERNALWeb制作を入口に、その会社が「AI前提で事業を運営する」第一歩をつくる。 内部 INTERNAL役員・社員・アルバイト・インターン含む全VAIZERが、この事業の運営を通じてAIを使いこなせるようになる「入り口（エントリー）」。

V/ENTERは小さな事業ではない。「生存のための仕事をなくす」というVAIZOミッション達成への 大動脈 である。3段階で繋がっていく。

EMBODY
自社で実証する
V/ENTERを通じて、VAIZO自身が「生存のための仕事をなくす」を体現する。AIに業務を委ねた事業構造を、まず自分たちの手で完成させる。

STAGE 02 — 破壊
DISRUPT
業界の構造を変える
事業が軌道に乗れば、既存の制作会社・コーディング会社に対する破壊的イノベーションになる。Web制作市場の常識そのものを書き換える。
→

NURTURE
健全な危機感を渡す
ここでの実績を持って、制作会社・関連事業者へ提案に伺う。健全な危機感を伴った「相手のニーズの醸成」を行う。次の市場を自ら作る。

VAIZO ─ COMMITMENT
04 / 07

3点を、必ず作る。

候補1社につき、デモ製作担当 VAIZER は 3点セット を必ず仕上げる。全件が対象。1点でも欠けた状態で送付してはならない。

COMMIT 01
カスタムデモ
DEMO
候補のWebサイトを下敷きに、業種・課題に合わせて構築するカスタム成果物。動くものを見せる。
追跡列 L デモ製作完成日
ログ種別 デモ完成
COMMIT 02
脆弱性レポート
VULNERABILITY REPORT
現サイトの構造的・体験的な問題点を整理した可視化資料。なぜ変える必要があるかを示す。
追跡列 M 脆弱性レポート完成日
ログ種別 脆弱性レポート完成
COMMIT 03
コンセプトシート
CONCEPT SHEET
どこに連れていくか、どう変わるかを言語化した提案の輪郭。デモを支える文脈を一枚で示す。
追跡列 N コンセプトシート完成日
ログ種別 コンセプトシート完成
RULE — NON-NEGOTIABLE L / M / N がすべて埋まって、初めて O列「3点セット送付日」へ進める。3点未完成での送付は禁止。
QUALITY AUDIT — 舛谷・橋本・外部デザイナーの主観判断による。3者のうち いずれか1名のGOで完成 と扱う。明文基準は設けない。

夕方の3分と、月曜会議。

夕方
G列ステージとJ列 次アクション期日を担当全件で確定。期日空欄のまま退社しない。
月曜

FAQ

3点が揃う前にメールしていい？
禁止。3点完成こそファーストタッチの条件。
3点の品質チェックは誰が？
舛谷・橋本・外部デザイナーの3者。いずれか1名のGOで完成と扱う。
どのファイルを使えばいい？
スライド03「ファイル構成」を参照。マスター以外は触らない。CTO V/ENTER handbook完成後はそれが業務マニュアルの正典。
期待値の付け方は？
月曜会議で議論決定。3点セットは全件作る前提。期待値は着手順を決める軸（S→A→B→C）。
次アクション＝次ステージ？
別概念。次アクション＝具体的な次の動き。次ステージ＝フロー上の段階。
